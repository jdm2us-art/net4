# Задание 2.
Рассчитать количество подсетей с префиксом /28 в сети 192.168.0.0/23.

В ответе указать количество и способ расчёта.

В сети 192.168.0.0/23 можно создать 2 подсети с префиксом /28 \
Префикс /28 означает, что 28 бит относятся к адресу сети. В исходной сети 192.168.0.0/23 первые 23 бита определяют сеть, а оставшиеся 5 бит — подсети. \
При переходе на префикс /28 (255.255.255.240) 5 бит из 5 оставшихся в последнем октете (для хостов) «заимствуются» для формирования подсетей. Это означает, что каждый из этих 5 бит может быть либо 0, либо 1, что даёт 2^5 = 32 возможные комбинации. \
Однако в контексте исходной сети с префиксом /23 эти 5 бит относятся к последней части адреса (октету). Таким образом, фактически формируется 2 отдельные подсети: одна с адресами, где последний октет равен 0 (192.168.0.0), и другая — с адресами, где последний октет равен 8 (192.168.0.8).

в) 172.16.30.1

Адрес сети — 172.16.30.128. Диапазон хостов — от 172.16.30.128 до 172.16.30.255 (всего 256 адресов, так как 2⁷ = 128, но два адреса (начальный и широковещательный) зарезервированы) 

Диапазон хостов: от 172.16.30.1 до 172.16.30.127 \

б) 172.16.30.199 — не входит в диапазон 172.16.30.128–172.16.30.191 \
в) 172.16.30.1 — находится в диапазоне 172.16.30.128–172.16.30.191 (в пределах сети) 


# Задание 4.
Необходимо выделить подсети из диапазона 192.168.255.0/24 для 2-х групп пользователей по 70 хостов.

В ответе указать адреса сетей для каждой группы, адреса шлюза и broadcast адрес для каждого диапазона. Ответить на вопрос, остались ли свободные подсети и пояснить ответ?

Диапазон 192.168.255.0/24 содержит 256 адресов (от 192.168.255.0 до 192.168.255.255 включительно). Из них два адреса зарезервированы: первый — адрес сети, последний — широковещательный адрес. Таким образом, доступно 254 адреса для хостов. \

Подсеть 1: 192.168.255.0/25 (диапазон: 192.168.255.0–192.168.255.126). \
Подсеть 2: 192.168.255.128/25 (диапазон: 192.168.255.129–192.168.255.254). \
Адрес сети для каждой подсети: 192.168.255.0 и 192.168.255.128 \
Широковещательный адрес для каждой подсети: 192.168.255.127 и 192.168.255.254 \
Доступные для хостов адреса: в первой подсети — от 192.168.255.1 до 192.168.255.126, во второй — от 192.168.255.129 до 192.168.255.254.

Свободных подсетей не осталось так как подсет 25 имеет 126 адресов в которые входят по 70 хостов, а следующая подсеть 26 имеет 62 адреса.
